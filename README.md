# Krishiv Singhal

A small, dependency-free personal website for GitHub Pages. Open `index.html` or serve this directory with a local HTTP server.

## Pages

- `index.html`: personal introduction, background, music links, and links into the work.
- `research.html`: modal logic, reinforcement learning, computational linguistics, and the two-variable logic talk.
- `projects.html`: the piano listening page, the personal language model, and Bitewise Labs apps.
- `piano/`: the listening page for Perpetuity, Chopin’s Nocturne Op. 9 No. 1, Chopin’s Etude Op. 10 No. 3, and Liszt’s “Paysage.”

Shared visual design lives in `style.css`; `script.js` adds voxel illustrations, a small world-turning interaction, and a light/dark theme switch. The text, navigation, and project notes remain available without JavaScript. Motion respects the visitor’s reduced-motion preference.

## Publishing

The public site is [krishivsinghal.github.io](https://krishivsinghal.github.io/). It is the repository `krishivsinghal.github.io`, published from the `main` branch at the repository root. No build step is required.

Do not publish the local CV PDF. The site does not link it.
